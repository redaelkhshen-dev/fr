# منصة مسيو رضا الخشن — دليل التشغيل

## الملفات
- `platform.html` — المنصة كاملة (طلاب + لوحة الأدمن)
- `firestore.rules` — قواعد أمان قاعدة البيانات
- `storage.rules` — قواعد أمان تخزين الملفات

## خطوات الإعداد (مرة واحدة)

### 1) إنشاء مشروع Firebase
1. ادخل https://console.firebase.google.com ← **Add project**.
2. من **Project settings ← Your apps** اضغط أيقونة الويب `</>` وسجّل تطبيق.
3. انسخ قيم `firebaseConfig` وضعها في أعلى ملف `platform.html` مكان `PASTE_...`.

### 2) تفعيل تسجيل الدخول
**Authentication ← Sign-in method ← Email/Password ← Enable.**
(المنصة تحوّل رقم الواتس داخليًا إلى بريد، فلا يحتاج الطالب لأي بريد.)

### 3) إنشاء حساب الأدمن (مهم — اعمله قبل نشر المنصة)
**Authentication ← Users ← Add user**
- Email: `admin@reda-fr.app`
- Password: كلمة سر الأدمن التي اخترتها

كلمة السر **غير مكتوبة في أي ملف**، وهي موجودة عند Firebase فقط. الدخول من الرابط:
`.../platform.html#/admin-login`

### 4) قاعدة البيانات
**Firestore Database ← Create database** (Production mode) ← تبويب **Rules** ← الصق محتوى `firestore.rules` ← Publish.

### 5) تخزين الملفات (PDF / Word)
**Storage ← Get started** ← تبويب **Rules** ← الصق محتوى `storage.rules` ← Publish.

> ملاحظة: Firebase قد يطلب ترقية المشروع لخطة **Blaze** (الدفع حسب الاستخدام، مع حصة مجانية) لتفعيل Storage. لو لا تريد ذلك، المنصة تسمح بوضع **رابط مباشر** (Google Drive) بدل رفع الملف.

### 6) النشر
- ارفع `platform.html` على GitHub Pages (نفس موقعك الحالي).
- **Authentication ← Settings ← Authorized domains** ← أضف `redaelkhshen-dev.github.io`.
- أضف رابط المنصة في قائمة الصفحة الرئيسية: `<a href="platform.html">منصة الطلاب</a>`.

## معلومات مهمة

**الفيديوهات:** ارفعها على يوتيوب كـ **Unlisted (غير مدرج)** مع السماح بالتضمين. المنصة تعرضها داخل حساب الطالب فقط، وتخفي عنوان الفيديو وزر المشاركة وفتح يوتيوب، وتضع اسم ورقم الطالب كعلامة مائية متحركة. لا توجد حماية 100% ضد تسجيل الشاشة أو استخراج رابط الفيديو من أدوات المتصفح — العلامة المائية هدفها ردع المشاركة وتحديد المصدر.

**الجهاز:** أول جهاز يدخل منه الطالب يتثبت عليه الحساب. لو غيّر جهازه أو مسح بيانات المتصفح، اضغط **"فك الجهاز"** من لوحة الأدمن.

**نسيان كلمة السر:** من لوحة الأدمن احذف الطالب، ثم احذف مستخدمه من Firebase ← Authentication ← Users، ثم يسجّل من جديد.

**حذف الطالب من اللوحة** يمنعه فورًا من الدخول؛ ولتحرير رقمه للتسجيل مجددًا احذفه أيضًا من Authentication.

## تحديث: تقدم الطالب
بعد أي تحديث لقواعد الأمان، انسخ محتوى `firestore.rules` من جديد إلى Firestore ← Rules ← Publish.
(إضافة حفظ تقدم المشاهدة تحتاج هذا التحديث؛ بدونه يُحفظ التقدم على جهاز الطالب فقط.)

## تحديث: موافقة المدرس على الطلاب الجدد
الطالب الجديد يسجّل بحالة **قيد المراجعة** ولا يدخل المنصة حتى تقبله من لوحة الأدمن (نظرة عامة ← طلبات التسجيل، أو تبويب الطلاب). عند القبول تتحوّل شاشته تلقائيًا إلى المنصة.
**مهم:** انسخ `firestore.rules` من جديد إلى Firestore ← Rules ← Publish، وإلا فسيفشل تسجيل أي طالب جديد.

## الدخول المستمر
الطالب والأدمن يبقى حسابهما مفتوحًا على نفس الجهاز حتى الضغط على «خروج». لو انقطع الإنترنت لا يُسجَّل خروج تلقائيًا، وتظهر شاشة «إعادة المحاولة».
لأفضل ثبات على الموبايل: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» (آيفون: مشاركة ← إضافة إلى الشاشة الرئيسية) فيفتح كتطبيق ولا يمسح المتصفح بياناته.
